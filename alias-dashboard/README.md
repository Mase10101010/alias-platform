# Alias Dashboard v1

Premium SaaS dashboard prototype for Alias, an AI concierge platform for hospitality.

## Run locally

```bash
npm install
npm run dev
```

The dev server is configured to start on port 5176.

## What is included

- Auth / trial entry screen
- Onboarding flow
- Dashboard overview
- Reservations page
- Analytics page
- Settings page
- Dark premium Alias design system
- Cyan Alias brand accent
